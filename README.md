# Dhruva Valluru — Personal Website

A modern personal website with three pages: Home, Projects, and About.

## Setup

1. Place your headshot image at `assets/headshot.jpg`
2. Open `index.html` in a browser (or use a local server)

## Structure

```
index.html    — Main HTML file with all three pages
style.css     — Styles (dark theme, responsive)
script.js     — Page navigation logic
assets/       — Images (headshot.jpg)
```

## Running Locally

Simply open `index.html` in your browser, or use a local server:

```bash
npx serve .
```
